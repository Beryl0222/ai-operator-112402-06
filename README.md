# 手写增删与 CTC 对齐接续

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

frame 是字符表各符号的自然对数概率，可用 null 表示不可能。路径相邻相同非 blank 折叠，再移除 blank。对齐某候选时将所有合法路径概率相加取对数，并给出一条最高分路径，平分取按字符表索引字典序最小者。确认命令指定文本前缀、最后一帧和所基于的修订，合法路径在该帧及以前折叠结果必须恰好等于确认文本。解除最近确认恢复前一次确认，不能为已解除的返回结果继续标记确认。输入由笔迹端保留，工作量预算计入对齐临时格点、状态及为未来对齐保留的辅助材料。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。put 给出片段 ID 与笔迹修订，confirm 给出修订、最后帧（含）与已确认字符序列。read 按修订查候选，undo 解除最近确认。
